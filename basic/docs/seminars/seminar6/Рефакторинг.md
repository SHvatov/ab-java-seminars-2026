# Рефакторинг

---

## Что это

Рефакторинг — изменение внутренней структуры кода без изменения его внешнего поведения. Цель — не добавить
функциональность, а сделать код читаемее и проще в сопровождении: то же самое поведение, выраженное яснее. Переписывание
императивного цикла в конвейер Stream API — типичный рефакторинг: команда на тех же входных данных даёт тот же вывод,
меняется только форма кода.

---

## Зачем

Код читают чаще, чем пишут. Императивный цикл с несколькими аккумуляторами прячет намерение: чтобы понять, что он
делает, нужно вычитать всё тело. Декларативный конвейер называет операции (`filter`, `groupingBy`) и тем самым выносит
намерение на поверхность. «Работает» — необходимое, но не достаточное условие; сопровождаемый код ещё и «читается».

---

## Принципы безопасного рефакторинга

- **Не менять поведение и структуру одновременно.** Сначала переписать реализацию при неизменном контракте метода
  (сигнатуре и наблюдаемом результате), убедиться, что вывод не изменился, и лишь потом, отдельным шагом, менять
  контракт, если это нужно. Смешение двух видов правок в одном шаге лишает возможности понять, что именно сломалось.
- **Малые шаги.** Крупное переписывание разбивается на серию мелких эквивалентных преобразований, после каждого из
  которых код остаётся рабочим. Так проще локализовать ошибку и в любой момент остановиться на рабочем состоянии.
- **Опора на проверку.** Уверенность, что поведение сохранилось, даёт повторяемая проверка. Пока это ручной прогон
  команды на тех же входных данных до и после правки; надёжный способ зафиксировать поведение — автоматические тесты,
  которые запускаются при каждом изменении и сразу сигнализируют о расхождении.

---

## Пример

Императивный подсчёт и его конвейерный эквивалент дают одинаковый результат:

```java
// До: намерение размазано по телу цикла
void before(Collection<Quote> quotes) {
    Map<Currency, Integer> byCurrency = new HashMap<>();
    for (Quote quote : quotes) {
        byCurrency.merge(quote.getInstrument().getCurrency(), 1, Integer::sum);
    }
}

// После: намерение названо операцией
void after(Collection<Quote> quotes) {
    Map<Currency, Long> byCurrency = quotes.stream()
            .collect(Collectors.groupingBy(
                    quote -> quote.getInstrument().getCurrency(),
                    Collectors.counting()));
}
```

Наблюдаемый результат один и тот же — распределение по валютам; изменилась только ясность записи. Это и есть рефакторинг:
поведение сохранено, читаемость выросла.
