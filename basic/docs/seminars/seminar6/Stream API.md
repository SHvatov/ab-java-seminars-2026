# Stream API

---

## Что такое стрим

Stream — не структура данных, а конвейер обработки последовательности элементов. Стрим не хранит данные и не изменяет
источник (коллекцию, из которой создан): он описывает набор операций, которые надо выполнить над элементами. Одну и ту
же задачу — «отфильтровать, преобразовать, собрать результат» — Stream API позволяет выразить декларативно: *что* нужно
получить, а не *как* пошагово это накопить.

---

## От коллекции к стриму: stream()

Метод `stream()` есть у любой `Collection`:

```java
void example(List<Instrument> instruments) {
    Stream<Instrument> stream = instruments.stream();
}
```

Из массива стрим создаётся через `Arrays.stream(array)`, из отдельных значений — `Stream.of(a, b, c)`. Обратно из
стрима в коллекцию возвращает терминальная операция — `toList()` или `collect(...)`.

---

## Промежуточные и терминальные операции

Операции стрима делятся на два вида:

- **Промежуточные** возвращают новый стрим и соединяются в цепочку: `filter`, `map`, `sorted`, `limit`, `distinct`.
- **Терминальные** запускают конвейер и дают результат или побочный эффект: `forEach`, `toList`, `count`, `reduce`,
  `collect`.

Стрим завершается ровно одной терминальной операцией. Типичный конвейер читается как одно предложение:

```java
void example(List<Instrument> instruments) {
    List<String> tickers = instruments.stream()   // источник
            .filter(i -> i.getCurrency() == Currency.RUB)  // промежуточная
            .map(Instrument::getTicker)                    // промежуточная
            .sorted()                                      // промежуточная
            .toList();                                     // терминальная
}
```

## Ленивость (холодность)

Промежуточные операции ленивы: пока не вызвана терминальная, не обрабатывается ни один элемент. До этого стрим — лишь
описание конвейера. Благодаря этому `limit` может остановить обработку, не проходя весь источник, а операции не создают
промежуточных коллекций на каждом шаге — элементы «протекают» через конвейер по одному.

Прямое следствие: стрим **одноразовый**. Повторный вызов терминальной операции на уже использованном стриме бросает
`IllegalStateException` — для новой обработки нужен новый стрим из источника.

---

## Основные промежуточные операции

- `filter(predicate)` — оставляет элементы, удовлетворяющие условию.
- `map(function)` — преобразует каждый элемент (например, инструмент → его тикер).
- `sorted()` / `sorted(comparator)` — упорядочивает; `Comparator.comparing(...).reversed()` задаёт обратный порядок.
- `limit(n)` — обрезает до первых `n` элементов; `skip(n)` — пропускает первые `n`.
- `distinct()` — убирает дубликаты (по `equals`).

```java
void example(List<Quote> quotes) {
    List<Quote> topGainers = quotes.stream()
            .sorted(Comparator.comparing(Quote::getChangePercent).reversed())
            .limit(3)
            .toList();
}
```

## Терминальные операции и коллекторы

- `forEach(action)` — выполняет действие над каждым элементом (побочный эффект, например печать).
- `toList()` — собирает в неизменяемый список.
- `count()` — число элементов.
- `reduce(...)` — сворачивает элементы в одно значение (сумма, максимум).
- `collect(collector)` — собирает результат по правилу коллектора.

Коллекторы (`java.util.stream.Collectors`) описывают, как собрать результат конвейера:

- `groupingBy(classifier)` — группирует в `Map` по ключу; со вторым коллектором считает по группам:
  `groupingBy(key, counting())`, `groupingBy(key, averagingDouble(...))`.
- `joining(sep)` — склеивает строки.
- `toMap(keyFn, valueFn)` — собирает в `Map`.

```java
void example(List<Quote> quotes) {
    Map<Currency, Long> byCurrency = quotes.stream()
            .collect(Collectors.groupingBy(
                    quote -> quote.getInstrument().getCurrency(),
                    Collectors.counting()));
}
```

## flatMap и Optional.stream()

`flatMap` разворачивает «стрим стримов» в один стрим. Частая идиома — отбросить отсутствующие значения без проверок на
`null`: `Optional.stream()` даёт пустой стрим для `Optional.empty()` и одноэлементный — для присутствующего значения.

```java
void example(List<String> tickers, QuoteService quoteService) {
    List<Quote> found = tickers.stream()
            .map(quoteService::quoteFor)   // String -> Optional<Quote>
            .flatMap(Optional::stream)     // оставляем только найденные
            .toList();
}
```

---

## Важные оговорки

- **Стрим не меняет источник.** `list.stream().sorted()` не сортирует `list`, а строит новый конвейер; исходная
  коллекция остаётся прежней.
- **Числовые стримы и точность.** `mapToInt`/`mapToDouble` дают специализированные стримы с `sum()`/`average()`. Но
  перевод `BigDecimal` в `double` теряет точность — для отображаемого среднего процента это приемлемо, для денежных сумм
  остаются `BigDecimal` и `reduce`.
- **Стрим — это слой абстракции поверх коллекции, а не замена ей.** Данные по-прежнему хранит коллекция; стрим лишь
  описывает их обработку.
