# Семинар 1 (продвинутый трек). Чеклист семинариста

**До семинара:**

- [ ] Убедиться, что презентация (знакомство → план курса → Market Pulse → ООП в Java (сжато) → устройство памяти
  JVM) есть в репозитории и отображается корректно.
- [ ] Проверить исходный код семинара: проект собирается, зависимость JOL (`jol-core`) уже подключена в
  `advanced/pom.xml`; `Stock.getDescription()`/`Bond.getDescription()`/`Etf.getDescription()`/`Stock.getDividends()`
  бросают исключение — это ожидаемо, реализуются на занятии; `Quote` в проекте ещё не существует — дописывается на
  занятии. `Portfolio` объявлен как интерфейс без реализации — реализация (`PortfolioImpl`) на занятии не пишется,
  это домашнее задание.
- [ ] Подготовить у себя готовую реализацию `Stock`, `Bond`, `Etf`, `Quote` — эталон для сверки по ходу семинара, и
  `PortfolioImpl` — эталон для проверки домашнего задания; студентам заранее не показывать.
- [ ] Открыть [README проекта](./Описание%20проекта.md) — по нему пройтись на этапе 1.
- [ ] Подготовить доску для брейншторминга.
- [ ] Проверить, что VisualVM установлен и запускается, JDK — версии, указанной в пререквизитах.
- [ ] Держать под рукой JVM-флаг `--add-opens java.base/java.lang=ALL-UNNAMED` на случай ошибки доступа к модулю
  при запуске JOL у кого-то из студентов.

### Этап 4. Доменная модель Market Pulse

- [ ] **Шаг 4.1.** Разобрать вместе со студентами уже данные `Currency` и `Instrument`.
- [ ] **Шаг 4.2.** Показать уже существующий `@Deprecated`-класс `InstrumentFormatter` (наивный `instanceof`-вариант)
  → обсудить, почему плохо → отрефакторить в полиморфизм (`getDescription()`), удалить `InstrumentFormatter`.
- [ ] **Шаг 4.3.** Показать, почему `double` не годится для денег; ввести `BigDecimal` с явным `RoundingMode`.
  Отдельно показать хрупкость `equals()` из-за `scale` (`"278.50"` vs `"278.5"`) и почему для сравнения по значению
  нужен `compareTo`/`Comparable`.
- [ ] **Шаг 4.4.** Обратить внимание, что `getDividends` бросает исключение в `Stock` → разобрать дилемму, которая
  возникла бы, попробуй мы добавить этот метод в `Instrument` (что возвращать в `Bond`/`Etf`?) → нарушение LSP →
  реализовать метод только в `Stock`.
- [ ] **Шаг 4.5.** Показать уже существующий `@Deprecated`-класс `StockSnapshot` (наивная попытка через
  наследование), показать, где она ломается → написать `Quote` с нуля как агрегацию, удалить `StockSnapshot`.
- [ ] Проговорить, что `Portfolio` (композиция) на семинаре не разбирается — это домашнее задание (см. раздел
  «Домашнее задание» в плане), а освободившееся время уйдёт на дополнительную самостоятельную практику с JOL
