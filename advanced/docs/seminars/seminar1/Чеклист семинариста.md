# Семинар 1 (продвинутый трек). Чеклист семинариста

**До семинара:**

- [ ] Подготовить презентацию: знакомство → план курса → Market Pulse → ООП в Java (сжато) → устройство памяти JVM
  (Heap/Non-Heap/Stack, сборка мусора обзорно) — готовится отдельно.
- [ ] Проверить исходный код семинара: проект собирается, зависимость JOL (`jol-core`) уже подключена в
  `advanced/pom.xml`; в `model` уже даны `Currency` и абстрактный `Instrument` — это стартовый код; `Stock`, `Bond`,
  `Etf`, `Quote`, `Portfolio` в нём ещё нет — дописываются на занятии.
- [ ] Подготовить у себя готовую реализацию `Stock`, `Bond`, `Etf`, `Quote`, `PortfolioImpl` — эталон для сверки по
  ходу семинара; студентам заранее не показывать.
- [ ] Открыть [README проекта](./Описание%20проекта.md) — по нему пройтись на этапе 1.
- [ ] Подготовить доску для брейншторминга.
- [ ] Проверить, что VisualVM установлен и запускается, JDK — версии, указанной в пререквизитах.
- [ ] Держать под рукой JVM-флаг `--add-opens java.base/java.lang=ALL-UNNAMED` на случай ошибки доступа к модулю
  при запуске JOL у кого-то из студентов.

### Этап 4. Доменная модель Market Pulse

- [ ] **Шаг 4.1.** Разобрать вместе со студентами уже данные `Currency` и `Instrument`.
- [ ] **Шаг 4.2.** Показать и реализовать наивный `instanceof`-вариант описания инструмента → обсудить, почему
  плохо → отрефакторить в полиморфизм (`getDescription()`).
- [ ] **Шаг 4.3.** Показать, почему `double` не годится для денег; ввести `BigDecimal` с явным `RoundingMode`.
- [ ] **Шаг 4.4.** Предложить наивный вариант — `getDividends` сразу в `Instrument` → разобрать дилемму по
  `Bond`/`Etf` → нарушение LSP → метод убран из `Instrument`.
- [ ] **Шаг 4.5.** Реализовать живьём наивную попытку `StockSnapshot` через наследование, показать, где она
  ломается → `Quote` как агрегация.
- [ ] Перед шагом 4.6 запушить текущее состояние кода, чтобы студенты подтянули актуальное состояние.
- [ ] **Шаг 4.6 — самостоятельно.** Раздать студентам функциональные требования и интерфейс `Portfolio` → студенты
  сами реализовали композицию. Сверить с `PortfolioImpl`.
