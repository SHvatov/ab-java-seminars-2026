# Семинар 2 (продвинутый трек). Чеклист семинариста

**До семинара:**

- [ ] Убедиться, что презентация (SOLID → паттерны GoF → picocli → Proxy) есть в репозитории и отображается
  корректно.
- [ ] Проверить исходный код семинара: проект собирается; `TypeFilter`/`NoOpFilter.matches()` бросают исключение —
  ожидаемо, их реализуют студенты самостоятельно (этап 6). Остальной код — доменная модель, `Factory Method`
  (включая `ServiceLoader`), `Iterator`, CLI-команды — уже рабочий, ничего из этого не пишется заново.
- [ ] Подготовить у себя готовую реализацию `TypeFilter`/`NoOpFilter` и одного из вариантов Proxy (JDK Dynamic Proxy
  или CGLIB) — эталон для сверки по ходу семинара; студентам заранее не показывать.
- [ ] Держать под рукой JVM-флаг `--add-opens java.base/java.lang=ALL-UNNAMED` — на случай ошибки доступа к модулю у
  тех, кто выберет CGLIB для самостоятельной работы (этап 8).
